# TaskFlux story: spine, colour contract and fact ledger

Audience: a non-technical visitor (class, panel, curious reader). One idea per screen, one headline, at most one short line.
Built with the same method as the NeuroPlastic story: tall pinned scroll tracks, every value a pure function of scroll progress,
big type, flat surfaces, one accent. Source: `story/src`. Build: `cd story && npm run site` (writes `site/index.html`).

## The running example

A car on a robot line. The design changes mid-build (a new roofline). Every car drawing is an **illustration** and says so.
The measured numbers come from a **simulated gearbox** (the process in `examples/gearbox.json`); the page says that too.

## Colour contract

| Colour | Means | Where |
|---|---|---|
| Indigo (accent) | The new design, the robot's action, emphasis words, links | Headline emphasis, TaskFlux bars, new roof |
| Teal | Work that stays | Kept parts |
| Rose | Work that must come off, or a cost | Old roof, wasted undo, damage |
| Amber | A step that cannot be undone | Locks, cured paint, "ask" |
| Grey | The old design, baselines, everything else | Neutral bars, machine, old parts |

Status colours appear only inside drawings, charts and their labels. Every status also has an icon or a label.
Palette: warm paper `#f5f2ec`, graphite ink `#1f1d1a`, indigo `#4f46e5`, teal `#0f766e`, rose `#be123c`, amber `#b45309`.
